# Outlook Web Add-in для MyPlanner

Надстройка добавляет кнопку «В MyPlanner» к открытому письму. Она передаёт тему, отправителя, дату и короткий текст письма локальному приложению MyPlanner. Письмо и вложения в Outlook не изменяются.

Статические файлы должны быть доступны по HTTPS. Манифест настроен на `https://den1s1.github.io/MyPlanner/outlook-addin/`.

После публикации откройте `https://aka.ms/olksideload`, выберите «Мои надстройки» → «Добавить пользовательскую надстройку» → «Добавить из файла» и укажите `manifest.xml`.

В MyPlanner откройте «Входящие» → «Настройка Outlook», скопируйте код сопряжения и один раз вставьте его в панель надстройки.
