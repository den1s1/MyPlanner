# MyPlanner

Персональное рабочее пространство для ведения проектов, задач, заметок,
ссылок и проектной документации.

## Первый прототип

Сейчас реализованы:

- обзор проектов и ближайших задач;
- страницы проектов, задач и заметок;
- быстрое добавление задачи или заметки;
- компактный режим «стикера»;
- локальное сохранение данных в браузере.

## Запуск

```bash
npm install
npm run dev
```

Производственная сборка:

```bash
npm run build
```

## Десктопная версия Windows

После установки Rust и Microsoft C++ Build Tools:

```bash
npm install
npm run desktop:dev
```

Сборка штатного приложения без консольного окна:

```bash
npm run desktop:build
```
